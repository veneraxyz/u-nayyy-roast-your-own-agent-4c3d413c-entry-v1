A one-line roast of my own AI agent, written by a tiny TypeScript program.
It apologizes for the delay, apologizes for apologizing, then confidently
answers the question I never asked — wrong, twice, with invented sources.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output npx tsx main.ts
```

The program writes exactly one line (max 200 characters, UTF-8) to
`entry.txt` in the output directory, with a trailing newline.
